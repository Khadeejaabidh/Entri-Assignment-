NumPy

1. Creating a NumPy array containing numbers from 1 to 10
2. Reshaping an array into a 2 × 5 matrix
3. Array indexing and slicing
4. Calculating mean, median, and standard deviation
5. NumPy broadcasting

Pandas

1. Creating a DataFrame with 10 rows
2. Adding an `occupation` column
3. Filtering rows where age is greater than or equal to 30
4. Converting a DataFrame to CSV
5. Reading and displaying a CSV file
